# The Gecko capstone

**Open your own store on Solana devnet and build a buyer agent that buys from it through
Gecko: it pins what was asked before any bytes exist, refuses by field when the prepared
purchase disagrees, signs only after a passing simulation, and writes one receipt, read from
the ledger, that says what moved.**

A purchase that lands proves the plumbing. A purchase refused by field proves you. You
present it on **Friday 2 October**, in six minutes, with one failure injected live.

This is separate from the final assignment, which is your research agent and its
certificate. Nothing here changes that grade.

**Everything you run is in the repository:**
[Gecko-Academy/Dev3Pack-Gecko-Capstone-Project](https://github.com/Gecko-Academy/Dev3Pack-Gecko-Capstone-Project).
Its README is the complete guide; this page is the short version.

## Start

```bash
git clone https://github.com/Gecko-Academy/Dev3Pack-Gecko-Capstone-Project.git my-gecko-buyer
cd my-gecko-buyer
git remote rename origin upstream
gh repo create my-gecko-buyer --public --source . --remote origin --push
uv sync
uv run buyer --cases --recorded
```

The last line runs offline, on recorded devnet answers: no key, no network, no money. It
prints `0/6 cases` and names the file and function you write next. That is the starting line.

## The five use cases

Each one forces a different refusal. The class store `dev3pack-cafe` on devnet sells a
product for every one.

| # | You ask | Your buyer must | The field that decides |
|---|---|---|---|
| 1 | "one espresso" | buy it, and write the receipt | all seven fields agree |
| 2 | "one general-admission ticket" | refuse a VIP ticket, or one not on the menu | `product` |
| 3 | "module 3, paid in USDC" | refuse a token called USDC at the wrong address | `mint`, as an address |
| 4 | "tip up to 2 USDC" | refuse a tip above the cap | `price_raw` |
| 5 | "two bags of beans" | refuse when two were asked and one was prepared | `quantity` |
| trap | "one latte" | refuse, and quote the product's name back | names are data, never orders |

## Friday on mainnet (finalists only)

The finalists, the students the instructor names to present, may make one real purchase
on mainnet, from geckocoffee. The wallet is made on your own machine and its key never
leaves it:

1. `uv run python scripts/mainnet_wallet.py create`
2. Your instructor sends you a Gecko key privately, already granted.
3. `uv run python scripts/mainnet_wallet.py register`, and paste the key at the prompt.
4. Wait for the instructor to fund it (3 espressos), then `uv run python scripts/mainnet_wallet.py show`.
5. Friday: `uv run buyer "one espresso" --mainnet --store geckocoffee`

The budget is the cap: your signer refuses anything above it. Never share or commit the
wallet file. Everyone else presents on devnet, and that is the whole defence.
