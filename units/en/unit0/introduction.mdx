# Welcome to the Dev3Pack AI Engineering Bootcamp

Three weeks, fifteen live sessions of two hours, one capstone: a source-grounded
research assistant you can install, test, evaluate, explain and defend.

## How the course is laid out

Everything you open lives under `units/en/`, one directory per unit, in the
order `units/en/_toctree.yml` gives:

| Where | What |
|---|---|
| `unit0/` | this welcome, onboarding, the runtime lanes, how to hand work in |
| `w01-…` to `w12-…` | week 0, the self-paced prerequisite |
| `session-01-…` to `session-15-…` | the fifteen live sessions, one per weekday |
| `capstone/` | the project you build between sessions from week 2 |
| `bonus-…` | optional reading, never counted |

Each unit holds an `introduction.mdx`, its concept pages, an exercise
`notebook.ipynb`, and once its session has run, a `solutions/` folder.

## What you need

A laptop with Python 3.11, `uv`, and a notebook editor. No API key: every scored
notebook runs offline against a deterministic model double. A real model is an
optional comparison lane, never a requirement.
